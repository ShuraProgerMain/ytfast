# YT Fast

Загрузчик видео с YouTube и X (Twitter) для Windows. Строка ввода открывается по **Ctrl+Alt+Y**:
ссылка подставляется из буфера обмена, загрузка начинается по Enter.

![Демонстрация](docs/demo.gif)

## Возможности

- Загрузка в несколько соединений: обходит ограничение скорости на одно соединение.
- Выбор качества от 480p до 2160p, а также «только звук».
- Загрузка фрагмента по времени начала и конца.
- Сохранённые папки с цветными метками.
- История загрузок.
- Кнопка «Скачать» на страницах YouTube в браузере.
- Несколько загрузок одновременно.
- Уже существующие файлы не перезаписываются.

## Скорость

При ограничении скорости на одно соединение (так бывает у некоторых провайдеров, около 100 КБ/с)
обычный `yt-dlp` качает ролик минутами. YT Fast получает от `yt-dlp` только прямые ссылки на
потоки, качает их частями в 32 соединения и склеивает через `ffmpeg` без перекодирования.

| Ролик | yt-dlp | YT Fast |
|---|---|---|
| 1080p60, 22 МБ | около 5 мин | 14 с |
| 4K60, 133 МБ | — | 58 с |

## Установка

Скачать архив (**Code → Download ZIP**), распаковать и запустить **`install.cmd`**. Или в PowerShell:

```powershell
irm https://raw.githubusercontent.com/ShuraProgerMain/ytfast/main/install.ps1 | iex
```

Права администратора не нужны. Установщик:

- ставит Python для текущего пользователя, если его нет (через winget или с python.org);
- скачивает `yt-dlp`, `ffmpeg` и JS-движок `deno` в `%LOCALAPPDATA%\YTFast\bin`; уже установленные
  в системе копии используются повторно, а при наличии Node.js 20+ `deno` не скачивается;
- добавляет команду `ytfast` в `PATH`;
- создаёт ярлык в меню «Пуск» и запускает фоновый процесс при входе в Windows.

Повторный запуск установщика обновляет программу и `yt-dlp`. Удаление: «Установка и удаление
программ» → YT Fast или `install.cmd -Uninstall`.

Требуется Windows 10 версии 2004 или новее либо Windows 11.

## Использование

### Окно

| Действие | Результат |
|---|---|
| **Ctrl+Alt+Y** | открыть строку ввода; повторное нажатие закрывает её |
| **Enter** | начать загрузку |
| **↓** или клик по качеству | выбрать качество; выбор сохраняется |
| **Esc** или клик вне окна | закрыть строку; во время загрузки она сворачивается в полоску в левом нижнем углу |
| наведение на полоску | кнопки «развернуть» и «остановить» |
| иконка папки | открыть папку загрузки |
| наведение на иконку папки → `⋯` | список сохранённых папок: выбрать, удалить, добавить |
| ножницы | загрузка фрагмента |
| часы | история загрузок |

Файлы сохраняются в последнюю выбранную папку, по умолчанию в `Загрузки\YouTube`.
Отсутствующая папка создаётся при загрузке. Если файл с таким именем уже есть, новый получает
имя вида `Название (2).mkv`.

### Фрагмент

Ножницы открывают таймлайн с двумя ползунками и поля **От** и **До**. Можно заполнить одно поле:
пустое «От» означает начало ролика, пустое «До» означает конец. Таймлайн появляется, когда программа
узнает длительность ролика (несколько секунд). Фрагмент вырезается без перекодирования, по ключевым
кадрам, поэтому он может начаться на 1–2 секунды раньше указанного времени.

### История

Хранит последние 100 успешных загрузок, в том числе запущенных из браузера. Для каждой записи
доступно «показать в папке», а если файл удалён — «скачать заново» с прежними настройками. Также
можно скопировать ссылку или удалить запись; сам файл при этом не удаляется.

### X (Twitter)

Ролики качаются только по прямой ссылке на видео, она оканчивается на `/video/1`. Ссылка на пост
не принимается. Посты, доступные только после входа в аккаунт, не поддерживаются. Режим «только звук» для X
недоступен.

### Кнопка в браузере

Расширение для Chrome, Edge, Brave и Vivaldi добавляет кнопку **Скачать** под роликом и в панель
Shorts, а также круглую кнопку в левый верхний угол миниатюры при наведении. Нажатие запускает
загрузку с последним выбранным качеством в текущую папку; прогресс показывается в полоске YT Fast.
При наведении на кнопку открывается список папок и пункт «Скачать фрагмент…» с мини-таймлайном.

Подключение:

1. Выполнить установку (`install.cmd`): она регистрирует связь расширения с программой.
2. Открыть `chrome://extensions` (в Edge — `edge://extensions`) и включить режим разработчика.
3. Нажать «Загрузить распакованное» и выбрать папку `extension` в папке программы.

### Командная строка

```bash
ytfast "https://www.youtube.com/watch?v=..." -q 1080
```

| Параметр | Назначение |
|---|---|
| `-q 720` / `1080` / `2160` | максимальная высота кадра; по умолчанию лучшее качество |
| `--audio` | только звук, m4a |
| `--h264` | H.264 + AAC в mp4 для плееров без поддержки VP9 |
| `-c 64` | число соединений, по умолчанию 32 |
| `-o папка` | папка сохранения |
| `--from 1:20` `--to 1:45` | фрагмент; можно указать только одну границу |

`ytfast` без аргументов открывает окно.

## Устройство

| Файл | Назначение |
|---|---|
| `ytfast.py` | загрузчик: ссылки через `yt-dlp -J`, загрузка частями в несколько соединений с повтором обрывов, фрагменты через локальный HTTP-мост для `ffmpeg`, склейка без перекодирования |
| `ytfast_gui.pyw` | окно и фоновый процесс: держит Tk и подготовленные ресурсы, перехватывает Ctrl+Alt+Y; повторный запуск передаёт команду через именованный канал, поэтому окно появляется примерно за 60 мс |
| `macui.py` | интерфейс в стиле macOS Big Sur на tkinter: размытый фон, тень, иконки, поле ввода |
| `extension/` | расширение браузера |
| `ytfast_host.py` | мост Native Messaging между расширением и фоновым процессом; принимает только ссылки на ролики YouTube |
| `install.ps1`, `install.cmd` | установка, обновление и удаление |
| `fonts/` | шрифт [Inter](https://rsms.me/inter/) (SIL OFL 1.1, `fonts/OFL.txt`), подключается только для программы; копия лежит в `extension/` |

Настройки хранятся в `%APPDATA%\ytfast\settings.json`, история — в `%APPDATA%\ytfast\history.json`,
журнал ошибок фонового процесса — в `%APPDATA%\ytfast\gui.log`.
