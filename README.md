# YT Fast

Быстрое скачивание роликов с YouTube на Windows: строка в стиле Spotlight по
**Ctrl+Alt+Y**, вставил ссылку, Enter — качается.

![Как пользоваться](docs/demo.gif)

## Зачем

Провайдер режет скорость YouTube **на каждое соединение** — около 100 КБ/с, и
обычный `yt-dlp` качает ролик минутами. YT Fast берёт у `yt-dlp` только прямые
ссылки на потоки, а сами потоки качает кусками в 32 соединения и склеивает
`ffmpeg` без перекодирования.

| Ролик | yt-dlp | YT Fast |
|---|---|---|
| 1080p60, 22 МБ | ~80 КБ/с, это ~5 мин | 14 с |
| 4K60, 133 МБ | — | 58 с |

## Как пользоваться

### Окно

| Действие | Что происходит |
|---|---|
| **Ctrl+Alt+Y** | открыть строку; ссылка из буфера обмена уже вставлена |
| **↓** или клик по `1080p ⌄` | выбрать качество — от «Лучшее» до «Только звук»; выбор запоминается |
| **Enter** | скачать |
| **Esc** или клик мимо окна | закрыть; во время загрузки окно сворачивается в полоску слева внизу |
| наведение на полоску | кнопки «развернуть» и «остановить» |
| **Ctrl+Alt+Y** ещё раз | убрать открытую строку |
| клик по иконке папки | открыть папку, куда сохраняется |
| наведение на папку → `⋯` | список сохранённых папок: выбрать, удалить (✕ у строки), «Добавить папку…» |

Папки — как шаблоны: путь и цвет метки, как в Finder; иконка папки в строке
окрашивается в цвет выбранной. По умолчанию выбрана папка, куда сохраняли в
последний раз (сначала — `Загрузки\YouTube`). Если папки ещё нет на диске, она
создастся при скачивании. Несколько загрузок можно запускать параллельно —
полоски встают стопкой.

### Кнопка на YouTube

Расширение для Chrome, Edge, Brave и Vivaldi добавляет синюю кнопку **Скачать** под ролик
и круглую — в левый верхний угол миниатюры при наведении: в поиске, на главной, в
рекомендациях. Одно нажатие — и загрузка идёт в полоске слева внизу, с последним выбранным
качеством и в текущую папку. При наведении на кнопку открывается список сохранённых папок:
клик по папке запускает загрузку в неё, и она становится текущей. Вкладка остаётся в фокусе.

Подключается один раз вручную, браузеры не дают сделать это скрипту:

1. запустить установку (`install.cmd`), она зарегистрирует мост к программе;
2. открыть `chrome://extensions` (в Edge — `edge://extensions`) и включить режим разработчика;
3. нажать «Загрузить распакованное» и выбрать папку `extension` в папке программы.

### Консоль

```bash
ytfast "https://www.youtube.com/watch?v=..." -q 1080
```

| Ключ | Что делает |
|---|---|
| `-q 720` / `1080` / `2160` | максимальная высота кадра (по умолчанию — лучшее) |
| `--audio` | только звук, m4a |
| `--h264` | H.264 + AAC в mp4 — для плееров, не понимающих VP9 |
| `-c 64` | число соединений (по умолчанию 32) |
| `-o папка` | куда сохранять |

`ytfast` без аргументов открывает окно.

## Установка

**Code → Download ZIP**, распаковать и дважды кликнуть **`install.cmd`**.

Или одной командой в PowerShell:

```powershell
irm https://raw.githubusercontent.com/ShuraProgerMain/ytfast/main/install.ps1 | iex
```

Скрипт всё сделает сам, права администратора не нужны:

- поставит Python, если его нет (через winget или с python.org, только для текущего пользователя);
- скачает `yt-dlp`, `ffmpeg` и JS-движок для YouTube в `%LOCALAPPDATA%\YTFast\bin` —
  в много соединений, тем же загрузчиком; то, что уже есть в системе, переиспользует.
  Если стоит Node.js 20+, используется он, и `deno` (93 МБ) не качается;
- добавит команду `ytfast` в `PATH`;
- создаст ярлык в «Пуск», автозапуск фонового процесса и запустит его.

На чистой Windows (проверено в Windows Sandbox) установка с нуля занимает около 5 минут.
Дальше — Ctrl+Alt+Y. Повторный запуск установки обновляет программу и yt-dlp.
Удалить — «Установка и удаление программ» → YT Fast (или `install.cmd -Uninstall`).

Нужна Windows 10 2004+ или Windows 11. Шрифт [Inter](https://rsms.me/inter/) лежит в
`fonts/` и подключается только для программы, в систему не ставится.

## Как устроено

| Файл | Что внутри |
|---|---|
| `ytfast.py` | загрузчик: ссылки через `yt-dlp -J`, многопоточная загрузка с докачкой обрывов и перехватом хвоста у медленных соединений, отмена, склейка `ffmpeg` |
| `ytfast_gui.pyw` | окно и фоновый процесс: держит Tk и готовые иконки, сам ловит Ctrl+Alt+Y, повторный запуск передаёт ему команду через именованный канал — поэтому окно появляется за ~60 мс |
| `macui.py` | интерфейс в духе macOS Big Sur поверх tkinter: размытый «вибрантный» фон из снимка экрана под окном, мягкая тень отдельным layered-окном, сглаженные иконки в духе SF Symbols, поле ввода |
| `extension/` | расширение браузера: кнопка на странице ролика и передача ссылки программе |
| `ytfast_host.py` | мост Native Messaging: принимает от расширения только ссылки на ролики YouTube и передаёт фоновому процессу, запуская его при необходимости |
| `install.ps1`, `install.cmd` | установка, обновление и удаление |
| `fonts/` | Inter под лицензией SIL OFL 1.1 (`fonts/OFL.txt`) |

Настройки — `%APPDATA%\ytfast\settings.json`, ошибки фонового процесса —
`%APPDATA%\ytfast\gui.log`.
